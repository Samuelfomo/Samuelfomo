# Bonjour, je suis Samuel Fomo 👋

**Développeur logiciel | Applications web, API et solutions métier**

📍 Douala, Cameroun · 💼 IMEDIATIS TechLab SARL

Je conçois et développe des applications web et des API destinées à répondre à des besoins métier concrets. Mon travail couvre notamment la conception de bases de données, le développement backend, les interfaces web et le déploiement d'applications.

- **Autres :** Authentification, applications multi-tenant, intégration d'API

## Fonctionnement

Chaque projet dispose d’une présentation et d’un journal d’évolution. La structure est volontairement documentaire : **pas de duplication des dépôts de code**, pas de secrets, pas de contenu client privé. Un projet peut être retiré ou reformulé si la propriété ou la diffusion de certaines informations est contestée.

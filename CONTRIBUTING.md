# Maintenir le catalogue

À chaque nouveau projet, créer `projets/nom-du-projet/README.md` et `projets/nom-du-projet/EVOLUTION.md`, puis l’ajouter à `projets/README.md`.

Pour chaque jalon, noter la **date**, le **changement**, son **statut réel**, les **preuves publiques** éventuelles et les **points en attente**.

Ne jamais publier : secrets, clés, configurations sensibles, données personnelles, contrats, captures privées, code non autorisé ou chiffres non vérifiés.

Distinguer systématiquement : projet personnel, contribution professionnelle, prestation client, collaboration et idée. Éviter les revendications de propriété non confirmées.

**Important :** la maintenance requiert une intervention explicite dans une conversation ou un processus automatisé effectivement configuré ; elle ne se déclenche pas d’elle-même après chaque discussion.
